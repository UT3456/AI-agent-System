ORDER CANCELLATION POLICY
- Orders can be cancelled free of charge as long as they are still in "Processing" status (not yet shipped).
- Once an order has been shipped, it can no longer be cancelled; the customer must start a return instead.
- To cancel, the support agent uses the order ID. A cancelled order is confirmed immediately and refunded within 3-5 business days.
- Cancellations are not possible for digital downloads or made-to-order items.
